Section A · about 5 minutes

Acid–base titrations

What a titration is for

Class notes
  • A titration finds the concentration of a solution, e.g. an acid, by reacting it with an alkali in the presence of an indicator.
  • One of the reagents must be a standard solution: its exact concentration is known. So if a precise volume is measured out, its moles can be calculated (n = c × V).

The white tile makes the colour change easier to see.

The steps in a titration

Class notes
  1. Fill a burette with the acid.
  2. Accurately measure 25 cm³ of the alkali standard solution using a pipette, and transfer it to a conical flask.
  3. Add a few drops of a suitable indicator to the alkali.
  4. Slowly add the acid from the burette, swirling constantly. As soon as the indicator changes colour, the alkali has been neutralised, so stop. Record the volume of acid added.
  5. Repeat until you get two results within 0.1 cm³ of each other (concordant). The mean of these two is the average titre.

Once you have an average titre, you can calculate the unknown concentration (Section D).

The notes call the acid "of known concentration" in step 1 and the alkali the "standard solution" in step 2. In a real titration only one of them is known: the other is the one you're finding.

The alternative: a pH meter

Class notes

Instead of an indicator, use a pH meter Handwritten: "not probe" to measure how the pH changes as base is added to acid.

  1. Measure the pH of the acid solution and record it.
  2. Add 1 cm³ of the base solution.
  3. Stir the mixture.
  4. Measure the pH and record it.
  5. Repeat until the base is in excess.
  6. Add base in smaller increments near the end point.

Key points about pH curves

Class notes
  • pH doesn't change in a linear way. Almost-horizontal sections mean adding base has very little effect. Vertical sections mean a tiny amount of base causes a large change in pH.
  • The starting point depends on the strength of the acid: strong acid starts ~pH 1, weak acid ~pH 3.
  • The end point of the curve depends on the strength of the base: strong base ends ~pH 13, weak base ~pH 9.
  • The mid-point of the vertical section is the equivalence point. Its volume is the average titre, which you use in calculations.
  • The length of the vertical section helps you choose an indicator (Section C).

Handwritten notes Weak acid + weak base: no vertical section. Weak acid + strong base: the flat part early on is where a buffer solution forms.

Careful with "end point"One handwritten note says "the end point is where the vertical section is". In the notes' own definitions (Section C), the equivalence point is the middle of the vertical section, and the end point is when the indicator changes colour. With the right indicator they happen at the same time.
Reading a curve backwardsIf the pH falls, acid is being added to a base. Then the start tells you the base's strength (~13 strong, ~11 weak) and the end tells you the acid's (~1 strong, ~3–5 weak).

Section C · about 5 minutes

Indicators

Two key terms

Class notes

Indicators show when a neutralisation is complete. They're one colour in acid and another in base.

Equivalence point
When exactly enough acid has been added to neutralise the base (or vice versa). The mid-point of the vertical section of the graph.
End point
The exact volume of acid or base that needs to be added to make an indicator change colour.

Choose an indicator so that the equivalence point and end point happen at the same time.

Extra help · "neutral"The notes say the colour change shows the mixture is "neutral". In this topic that means exactly neutralised (equivalence), which isn't always pH 7. For a weak acid + strong base it's about pH 8.7.

Section D · about 6 minutes

Titration calculations

The 4 steps

Class notes
1 · Balanced equation→2 · n = c × V for the known solution→3 · Use the ratio→4 · c = n ÷ V for the unknown

Volumes in dm³: cm³ ÷ 1000.

From the notesTry it first

30 cm³ of NaOH solution of concentration 0.23 mol dm⁻³ was titrated against HNO₃ of unknown concentration. The equivalence point on the titration curve is at 25.0 cm³. Calculate the concentration of the HNO₃.

Curve redrawn for this exact reaction (HNO₃ added to NaOH), so the pH falls. The notes' sketch shows a different shape.

[HNO₃] =mol dm⁻³
  1. Balanced equation: NaOH(aq) + HNO₃(aq) → NaNO₃(aq) + H₂O(l) (the notes write H₂O(s): water here is a liquid)
  2. Moles of the known: n(NaOH) = 0.23 × (30 ÷ 1000) = 0.0069 mol
  3. Ratio: 1 : 1, so 0.0069 mol of HNO₃ reacted.
  4. Concentration: c = 0.0069 ÷ (25.00 ÷ 1000) = 0.276 mol dm⁻³
About the notesThe text says "the average titre … was 24.0 cm³", but the circled reading on the graph and the division both use 25.00 cm³. 25.0 is the intended value. With 24.0 you'd get 0.288 mol dm⁻³.

H₂SO₄ + 2NaOH → Na₂SO₄ + 2H₂O

mol dm⁻³
  1. n(NaOH) = 0.100 × 0.0250 = 2.50 × 10⁻³ mol
  2. Ratio 1 : 2, so n(H₂SO₄) = 2.50 × 10⁻³ ÷ 2 = 1.25 × 10⁻³ mol

Wrap-up · about 4 minutes

Summary

  • Titration finds an unknown concentration using a standard solution (exact concentration known).
  • Pipette 25 cm³ into a conical flask, add indicator, add from the burette while swirling, stop at the colour change. Repeat to concordant titres (within 0.1 cm³).
  • pH meter method: add base in small steps, stir, record pH. Smaller steps near the end point. Calibrate with a solution of known pH.
  • Curve start = acid strength (~1 strong, ~3 weak). Curve end = base strength (~13 strong, ~9 weak).
  • Equivalence point = mid-point of the vertical section. End point = indicator changes colour.
  • A suitable indicator changes colour on the vertical section. Phenolphthalein for strong bases, methyl orange for strong acids, either for strong + strong, neither for weak + weak.
  • Calculation: equation → n = cV → ratio → c = n ÷ V.
