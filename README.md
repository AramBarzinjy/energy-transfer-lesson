# Study library

Self-paced AQA A-level lessons, opened at https://arambarzinjy.github.io/energy-transfer-lesson/

- `index.html`: home screen with subject folders
- `biology/index.html`: Biology topics (add new topics to the `TOPICS` list there)
- `chemistry/index.html`: Chemistry topics (same `TOPICS` list pattern)
- `<subject>/<topic>/`: each topic's interactive lesson and PowerPoint
- `assets/`: shared styles, lesson engine and app icons
